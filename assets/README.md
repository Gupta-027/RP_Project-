# NIT Rourkela emblem

`nit_rourkela_logo.png` is the unmodified PNG used by the
[official NIT Rourkela website](https://www.nitrkl.ac.in/).

Original asset: <https://www.nitrkl.ac.in/assets/images/logo.png>

It is bundled locally for the requested research-project introduction, so the
opening page does not depend on an external image request at runtime. The emblem
is displayed in its original colours. Student and supervisor details on the page
were supplied by the project author. The faculty profile is available at
<https://www.nitrkl.ac.in/ID/~bbv/>.
